# TaskFlow DB

## Description

TaskFlow DB is a MongoDB-integrated backend API built using Node.js, Express.js, and Mongoose.

It provides persistent cloud database storage for task management.

---

## Features

- MongoDB Atlas Integration
- Mongoose Schema Validation
- CRUD Operations
- REST API
- Error Handling
- Middleware Support
- Secure Configuration

---

## Technologies Used

- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- dotenv

---

## Installation

```bash
npm install
```

---

## Run Server

```bash
npm start
```

---

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | /api/tasks | Get all tasks |
| GET | /api/tasks/:id | Get task by ID |
| POST | /api/tasks | Create task |
| PUT | /api/tasks/:id | Update task |
| DELETE | /api/tasks/:id | Delete task |
